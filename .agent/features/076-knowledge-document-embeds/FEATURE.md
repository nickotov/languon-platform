# Knowledge document website and image embeds

Status: Complete

Authors can insert remote resources into a Knowledge document and see them in the saved reader.

- AC-1 — Find Video when searching for YouTube and play valid YouTube links using the existing player.
- AC-2 — Insert a website or an image using a labeled HTTPS URL field. Cancel preserves content and invalid input can be corrected. A document containing just an embed can be saved.
- AC-3 — Preserve type, URL and position through editing, saving, reading and copying. Readers can load each resource inline, identify its host and open the original even when embedding fails.
- AC-4 — Expand a website or image into an accessible, dismissible dialog up to 90dvw by 90dvh. Preserve image proportions and provide keyboard access on narrow and desktop screens.
- AC-5 — User activation precedes external requests. Website previews display sandboxed content. Remote content and URLs are excluded from model context. Existing YouTube playback and writer capabilities remain scoped.

Extend the approved insert menu and dialog patterns. The knowledge workspace and interactive workbook guides cover current editing and reading. The new embed guide maps verification of this journey. There are no uploads or server-side downloads.
