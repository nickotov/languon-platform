## E-WEB-SSE-BOUNDARY — Real browser stream protocol remediation

- Browser reproduction: persisted turns completed while the desktop/mobile panel retained an incomplete empty assistant row and preparing indicator. The backend SSE route emits `event: conversation` for canonical data, `event: heartbeat` with `{}` for idle keepalive, and `event: unavailable` with `{}` for source/access or stream failure. The web API adapter incorrectly schema-parsed every SSE data block as `ConversationEvent`, so a heartbeat or unavailable control raised a `ZodError` and interrupted the subscription.
