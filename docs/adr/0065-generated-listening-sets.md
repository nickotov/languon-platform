# Generate and publish listening sets under bounded speech authority

## Decision

Represent a listening set with the existing Audio block and linked exercise blocks. Synthesis is a durable prerequisite. The validated script precedes provider dispatch and the assembled media provides actual transcript segment timing. A two-speaker script pins distinct configured voices. Only the owner’s permitted, playable media and a matching transcript may ground a listening question.

Reusing a recording requires no speech authorization. New recordings require explicit bounded speech authority associated with the lesson admission. Delegate paid utterance work from that authority and keep resumable state separate from model-authored material. Worker roles should exercise only lease-scoped capabilities. Existing document insertion and explicit Save continue to govern publication.

## Consequences

Authors can review several questions around a single player and subsequently edit each document block. Replaying an excerpt or revealing a transcript does not create a provider request. Measured utterance boundaries make short dictation possible without a separate alignment model. Dialogue quality remains dependent on available distinct voices and requires a separate real-voice readiness check.
